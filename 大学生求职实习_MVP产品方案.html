在校大学生求职 / 实习
信息差与焦虑的产品解法

他们不缺努力，缺的是"现在该做什么、我算不算正常、投出去为什么没回音"的确定感。本报告定义核心用户与痛点，并给出一个能在 4–6 周内上线、可被验证的 MVP。

🎯 核心人群：大三—研二 · 非顶尖资源型学生 📦 形态：微信小程序（免下载 · 强分享） 🚀 V1 功能：3 个
需求一 · P0

机会的确定性——按我的背景，精准、及时、不踩坑地知道"有什么能投、还剩几天"。

需求二 · P0

即时可执行的反馈——知道我的简历、我和目标岗位差在哪，以及怎么立刻改。

需求三 · P1

不孤独——看到真实的同辈进度、有人可问，把焦虑校准成行动。

01 · Target User

核心目标用户画像

求职焦虑并非人人相同。顶尖院校学生有校友网络与内推托底，信息差痛点反而弱；真正被信息差困住的，是缺少"内部人通道"的大多数。

大一 — 大二
探索型

不知道路径长什么样，痛在"认知空白"，但紧迫感低、付费与留存弱。

大三 — 研一 ◆ 核心
实习冲刺型

时间紧、要结果，信息差直接决定能否上车，痛感与活跃双高。

大四 — 研二
校招决战型

焦虑峰值、愿为结果付费，但窗口期短、留存窗口窄。

02 · Pain Points

痛点清单：区分"症状"与"根因"

学生嘴里说的往往是症状（"海投没回音"）。持续追问"为什么"，才能挖到可被产品解决的结构性根因。

PAIN 01信息层

机会分散且滞后，"知道时已截止"

症状信息散落在几十个公众号、群聊、官网和招聘 App，提前批/正式批/补录节点不透明。
根因企业招聘时间线不统一，且没有一个"以学生为中心、按截止时间组织"的聚合视图。

代价：错过窗口，只能被动等补录或下一年。

PAIN 02信息层

真伪难辨，被贩卖焦虑与骗局收割

症状JD 千篇一律、岗位真实情况未知，"付费内推""小黑工"和软广混杂。
根因缺乏来自同龄人的、可追溯的一手反馈，学生没有判断依据。

代价：钱与时间双失，对求职信息整体失去信任。

PAIN 03能力层

简历与投递是黑箱，没有即时反馈

症状"已读不回"，不知道自己简历什么水平、卡在哪。
根因HR 筛选标准不公开，学生手里没有可对标的样本和评分尺度。

代价：同一份烂简历被海投上百次，把问题误判为"自己不行"。

PAIN 04能力层

能力差距不可见，准备没有路径

症状想去某岗，却不知道要补什么技能/项目，盲目刷证、报班。
根因JD 要求与个人现状之间，缺少一份结构化的"差距—行动"对照。

代价：努力用错方向，几个月后仍达不到门槛。

PAIN 05心态层

同辈压力与进度焦虑（FOMO）

症状"是不是只有我还没 offer？"反复刷帖，越看越慌。
根因缺少匿名、健康的横向进度参照，只能拿别人的高光时刻对比自己。

代价：情绪内耗，甚至因焦虑而降低投递质量、躺平。

PAIN 06心态层

无人可问，试错成本高

症状没有行业人脉，敢问的学长学姐少，自我介绍/面试没人陪练。
根因能提供帮助的"弱关系网络"缺失，且单次提问有社交负担。

代价：独自踩坑，本可避免的错误反复发生。

04 · MVP Features & Interaction

MVP 功能清单与交互方案

产品暂定名 「上岸地图」。第一个版本只做三件事：告诉你投什么 → 帮你过简历关 → 让你知道自己不是一个人。

功能一 · 机会雷达（个性化求职时间线）

对应 N1 ｜ 解决痛点 1、2：信息分散滞后、真伪难辨

核心交互模块

  • 一次性画像问卷（60 秒）：学校 / 专业 / 年级 / 方向 / 意向城市 / 行业，决定推荐基线。
  • 时间线信息流：按"截止日期"排序的岗位卡，标注匹配度、还剩 X 天、批次（提前批/正式批/补录/日常实习）。
  • 可信投递入口：每张卡只放官方投递链接，显著标注信息来源与更新时间，拒绝来路不明的"内推"。
  • 订阅 + 提醒：订阅方向后，截止前通过小程序服务通知推送；一键加入"我的投递看板"。
V1 取巧：不追求全行业，先只做互联网「产品 / 运营 / 技术」3 个方向；岗位库 = 官方来源半自动采集 + 人工每日精选核对，保证"及时且真"。

用户使用路径

进入小程序 → 完成 60 秒画像选年级、目标方向与城市，系统即时生成首屏时间线。
浏览"为你排序"的岗位卡默认按截止时间排列，一眼看到最紧急且匹配的机会。
查看岗位详情与可信入口核对来源、更新时间、批次与匹配度，排除骗局。
订阅方向 / 开启截止提醒新机会与临期岗位由服务通知主动触达。
加入投递看板 → 前往官方投递状态可标记（待投/已投/笔面/Offer），形成个人求职台账。

功能二 · 简历体检（投递前安检）

对应 N2 ｜ 解决痛点 3、4：简历黑箱、差距不可见

核心交互模块

  • 上传简历 + 粘贴/抓取 JD：PDF 或图片，目标岗位描述可粘贴链接。
  • 30 秒出体检报告：岗位匹配度分数、过筛风险点、缺失/可强化关键词。
  • 逐条改写建议：按 STAR 结构把"做了什么"改成"带来什么结果"，可一键复制。
  • 差距清单：该岗位看重而你欠缺的技能/项目，给出"可在 X 周内补齐"的轻提示（学习内容后置）。
V1 取巧：大模型 + 一套按岗位沉淀的能力评分 Rubric（规则兜底 + LLM 生成），冷启动质量可控；"上岸简历对照"先用结构化范例，UGC 沉淀后再替换真实样本。

用户使用路径

从岗位卡点"投递前先体检"或在功能区直接上传简历并粘贴目标 JD。
等待约 30 秒生成报告先看匹配度总分与最高优先级的 3 个风险。
逐条查看并采纳改写建议右侧原文对照，复制改写后的句子回简历。
查看差距清单判断这个岗位是否值得投、还需补什么。
更新简历 → 回到岗位卡完成投递形成"诊断—修改—投递"闭环并记入看板。

功能三 · 进度广场（匿名同辈地图）

对应 N3 ｜ 解决痛点 5、6：进度焦虑、无人可问

核心交互模块

  • 一键匿名报进度：公司 × 岗位 × 当前阶段（刚投/笔试/面试/Offer/被拒），无需经营人设。
  • 真实进度地图：按"公司+岗位"聚合，回答最揪心的问题——"这个岗现在发到哪一步了？"
  • 一手面经与时间线：每个节点可附一句真实体验，成为可信的反软广信息源。
  • 轻量互助提问：每日限免提问、过来人抢答，去除一对一社交负担；运营引导善意氛围。
V1 取巧：发布做到极简（3 次点击），开屏即看不用注册人设；上线前由运营预置 50+ 条种子进度，先在 3 所目标高校小范围激活。

用户使用路径

从投递看板"匿名报个进度"选公司、岗位、当前阶段，3 次点击完成，可附一句话。
进入进度广场搜目标公司/岗位看到真实的阶段分布，而不是别人的高光截图。
查看面经与时间线判断自己是否正常、下一步大概何时到来。
提出一个具体问题 / 回答他人每日限免，弱社交、被接住，不必怕打扰。
焦虑被校准 → 回到投递行动"原来多数人也还在投"，把内耗转成下一次投递。

⭐ 首版黄金路径（端到端，验证留存的关键链路）

60 秒画像→ 收到个性化时间线→ 看中一个岗位→ 简历体检并修改→ 官方投递 + 记入看板→ 匿名报进度 / 看真实节奏→ 截止提醒带来下一次回访投递
05 · Launch & Validation

上线节奏、成功指标与边界

"快速上线"的本质是先验证最危险的假设，而不是一次做全。形态选微信小程序：免下载、贴合大学生、天然支持分享裂变与服务通知。

🗓 4–6 周排期

W1画像 + 3 方向岗位库（人工+半自动）
W2机会时间线、提醒、投递看板
W3AI 简历体检（Rubric+LLM）
W4匿名进度广场 + 种子内容
W5联调，3 所高校灰度
W6校招/实习季放量

📊 成功指标

北极星：7 日内完成"有效投递"的用户占比（经本产品投递且进入企业流程）。
  • 激活：画像完成率、首屏时间线生成率
  • 价值：简历体检使用率、诊断后 24h 内投递率、人均周投递数
  • 留存：招聘季次周留存、服务通知点击率
  • 广场：进度发布率、人均查看公司数、提问响应率

🚧 V1 明确不做（控制范围）

不做全行业全岗位覆盖
不做课程售卖 / 付费内推（信任红线）
不做真人 1v1 辅导
不做实名社交关系链
不做完整 ATS 投递系统
不做学习课程内容（仅给差距提示）

🧪 上线前先做"代运营 MVP"

  • 在求职微信群里人工每日推送 3 方向岗位 + 人工批改简历，观察 7 日主动回访率。
  • 手工维护岗位库 2 周，量化"及时性"所需工时，判断能否规模化。
  • 邀请 20 位实习生报进度，测匿名 UGC 的自然发布率。

最危险的假设：学生愿意把求职托付给一个新入口。这一项被验证前，不投入完整开发。

关键假设与证伪信号

A1 用户假设：需要新入口

证伪信号：代运营群 7 日留存低、无人主动求岗位/改简历。

A2 供给假设：信息可低成本聚合

证伪信号：3 方向人工维护工时远超 1 人/日，时效无法保证。

A3 内容假设：UGC 能自然发生

证伪信号：种子之外几乎无自发进度发布，广场沦为单向公告。
